# [CPF-004] The extension is called Shortcuts

**Status**: Open
**Priority**: Medium
**Component**: `src/CmdPal.Extension.Folders/FoldersCommandsProvider.cs`, `src/CmdPal.Extension.Folders/Package.appxmanifest`

**Summary**:
As a user of Command Palette, I want the extension to appear as "Shortcuts", so that its name
says what it gives me rather than how it finds it.

**Description**:
Found in the UAT of CPF-002c: "Folders" is a dull name. The name the user sees is the provider's
`DisplayName` and the manifest's display names (`Properties/DisplayName`,
`uap:VisualElements`, `com:ExeServer`/`com:Class`, `uap3:AppExtension`). The package identity
(`CmdPal.Extension.Folders`), the repository, the project and the settings keys stay — changing
them would make Windows see a new package and lose the saved settings.

**Acceptance Criteria**:
- [ ] Command Palette shows the extension as "Shortcuts" in its list of installed extensions and on its settings page
- [ ] Settings saved before the rename are still there after it
