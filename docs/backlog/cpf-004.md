# [CPF-004] The repository and the extension are called Shortcuts

**Status**: In Progress
**Priority**: Medium
**Component**: the whole repository — `src/CmdPal.Extension.Folders/`, `tests/CmdPal.Extension.Folders.Tests/`, `.github/workflows/ci.yml`, `README.md`, `AGENTS.md`

**Summary**:
As a user of Command Palette, I want the extension and its repository to be called
"Shortcuts", so that its name says what it gives me rather than how it finds it.

**Description**:
Found in the UAT of CPF-002c: "Folders" is a dull name. The GitHub repository becomes
`xxthunder/CmdPal.Extension.Shortcuts` (GitHub redirects the old URL). In the code: the
extension project, its folder, namespace and classes (`FoldersExtension`,
`FoldersCommandsProvider` → `Shortcuts…`), the test project, the package identity
(`CmdPal.Extension.Shortcuts`), the executable, the COM class GUID, the settings namespace, and
every display name — "Shortcuts". CI paths, README and AGENTS.md follow.

What stays: the library `FoldersCatalog` (it catalogues folders — the name says what it does),
`tools/catalog.cs`, the ID prefix `CPF`, and closed backlog items, which record what was true
when they closed. Open items name the new paths.

**Scope Decisions**:
- **2026-11-08 — Identity changes too**: at the author's request the package identity and the
  repository are renamed, not only the display name. Windows sees a new package: the old
  development registration is removed, and the settings — saved only on the author's machine —
  are entered again rather than migrated.
- **2026-11-08 — New COM class GUID**: the new package gets a GUID of its own, so that a leftover
  registration of the old one cannot answer for it.

**Acceptance Criteria**:
- [ ] The GitHub repository is `xxthunder/CmdPal.Extension.Shortcuts`; the old URL redirects
- [ ] Projects, folders, namespace, classes, package identity, executable and settings namespace are named Shortcuts; no `Folders` remains outside `FoldersCatalog`, `tools/` and closed items
- [ ] Command Palette shows the extension as "Shortcuts" in its list of installed extensions and on its settings page
- [ ] CI builds and tests under the new names
