# [CPS-012] A script's earlier arguments are offered again

**Status**: Open
**Priority**: High
**Component**: `src/CmdPal.Extension.Shortcuts/ScriptArgumentsPage.cs`, `src/CmdPal.Extension.Shortcuts/ShortcutsCommandsProvider.cs`, `src/FoldersCatalog/`, `README.md`

**Summary**:
As a user of `~\shortcuts`, I want the arguments I gave a script before offered again, so
that `px-proxy stop` takes one keystroke after the first time, as it did in Keypirinha.

**Description**:
Since CPS-009, Ctrl+Enter on a `.ps1`, `.bat` or `.cmd` opens a parameters page with one
text field; its text becomes the arguments. Every run types them again. Keypirinha keeps
the arguments used before for each item and offers them when the item is locked in, so
`start` and `stop` for `px-proxy` are picked, not typed. It is the last thing Keypirinha
does that the extension does not.

This item is the follow-up named by the CPS-009 Scope Decision *Optional: earlier
arguments*.

Open before the build: whether the SDK's `ParametersPage` can show a list next to its text
field. If it cannot, the earlier arguments need another place, for example a list page of
their own on Ctrl+Enter with a "new arguments" entry that opens today's page, or one
command per earlier argument on the item.

**Scope Decisions**:
- **Per script**: the earlier arguments belong to the script's full path; two scripts with
  the same name keep separate lists.
- **The history is the library's**: adding, ordering and capping the list live in
  `FoldersCatalog`, so they are tested on Linux; the extension only stores and shows it.
- **At most 10 per script** (the author, 2026-11-13): the oldest falls off when an eleventh
  is added.

**Acceptance Criteria**:
- [ ] Before the build, it is confirmed how the SDK shows a list with a parameters page, and
      the chosen place is a Scope Decision in this item
- [ ] After `px-proxy stop` has run once from the parameters page, `stop` is offered for
      `px-proxy` and runs it without typing
- [ ] The most recently used arguments come first; a repeated argument string appears once
- [ ] The list per script holds at most 10 entries
- [ ] The earlier arguments survive a restart of Command Palette
- [ ] New arguments can still be typed
- [ ] All existing tests continue to pass
