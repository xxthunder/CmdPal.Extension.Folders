# [CPS-007] Badges in the README, coverage on Codecov

**Status**: Open
**Priority**: Medium
**Component**: `README.md`, `.github/workflows/ci.yml`, both test projects

**Summary**:
As the author, I want the README to show whether CI is green and how much of the code the tests cover, so that the state of the repository is visible at a glance.

**Description**:
A CI badge comes from GitHub Actions (`…/actions/workflows/ci.yml/badge.svg`). Coverage: `coverlet.collector` back in both test projects (it was removed in CPS-002a as unused), the tests run with `--collect:"XPlat Code Coverage"`, and `codecov/codecov-action` uploads the Cobertura files from the Linux job (library) and the Windows job (library and extension), told apart by flags. Codecov provides the coverage badge.

The author's step, as it is a credential: sign in to codecov.io with GitHub, enable the repository, and store its upload token as the secret `CODECOV_TOKEN`.

**Acceptance Criteria**:
- [ ] The README shows the CI badge and the Codecov coverage badge
- [ ] CI uploads coverage from the Linux and the Windows job on every pull request, and Codecov shows both
- [ ] A pull request without the secret (e.g. from a fork) still passes CI
