# [CPS-011] A new user sees how to choose folders when the catalogue is empty

**Status**: Open
**Priority**: Medium
**Component**: `src/CmdPal.Extension.Shortcuts/Helpers/SettingsManager.cs`, `src/CmdPal.Extension.Shortcuts/ShortcutsCommandsProvider.cs`, `README.md`
**Related**: [CPS-010](cps-010.md) (Store release, which this item comes before), [CPS-002c](cps-002c.md) (folders and extensions as settings)

**Summary**:
As someone who installed Shortcuts from the Gallery or the Store, I want the extension to tell me how to choose my folders when it finds nothing, so that I do not take an empty catalogue for a broken extension.

**Description**:
The default folders are `%USERPROFILE%\shortcuts\**` and `%USERPROFILE%\shortcuts_private\**`
(`SettingsManager.DefaultPatterns`), the author's own. For anyone else neither folder exists:
the extension adds nothing to the main search and gives no sign that it runs or that it has
settings. Once the extension is in the Store (CPS-010), that is the first thing a stranger
sees.

Two changes:
- **One default folder**: `%USERPROFILE%\shortcuts\**`. `shortcuts_private` is the author's
  setup; the author's shortcuts repository sets the folders when it installs the extension.
- **A hint when the catalogue is empty**: the extension lists one top-level command, e.g.
  "Shortcuts: no files found, choose your folders", that opens the extension's settings. It
  goes as soon as the catalogue holds a file, and comes back when it is empty again.

A changed default reaches only users without saved settings; the author's machine keeps the
folders saved in its settings file.

Raised on 2026-11-13.

**Scope Decisions**:
- **Hint over a different default** (the author, 2026-11-13): a folder everyone has, such as
  Desktop or Documents, would work at once but duplicate what Command Palette finds already
  and change the author's setup. The default stays the shortcuts folder; the hint makes the
  empty state explain itself.

**Acceptance Criteria**:
- [ ] The default folders are `%USERPROFILE%\shortcuts\**` only
- [ ] With an empty catalogue, the main search shows one command that names the problem and opens the extension's settings
- [ ] The hint disappears as soon as a configured folder holds a matching file, without a restart
- [ ] The README says how to choose folders after installing

**Dependencies**:
- None. [CPS-010](cps-010.md) waits for this item.

- Does the shortcuts repository already write the folders into the extension's settings on install, or does that need an item there (next to SC-086)?
