# [CPS-010] Shortcuts is in the Command Palette Extension Gallery, installed from the Microsoft Store

**Status**: Open
**Priority**: Medium
**Component**: `src/CmdPal.Extension.Shortcuts/Package.appxmanifest`, `src/CmdPal.Extension.Shortcuts/CmdPal.Extension.Shortcuts.csproj`, `src/CmdPal.Extension.Shortcuts/Assets/`, `.github/workflows/`, `README.md`; outside the repository: Partner Center, a pull request to `microsoft/CmdPal-Extensions`
**Related**: [CPS-002](cps-002.md) (epic, its distribution decision), [CPS-002e](cps-002e.md) (superseded by this item), [CPS-005](cps-005.md) (own icon, a prerequisite)

**Summary**:
As a Command Palette user, I want to find Shortcuts in the Extension Gallery in Command Palette's settings and install it with one click, so that I get it without building it or trusting a certificate.

**Description**:
The Extension Gallery (PowerToys 0.100) is a curated list in
[microsoft/CmdPal-Extensions](https://github.com/microsoft/CmdPal-Extensions): one folder per
extension, `extensions/<author>/<extension-name>/` with an `extension.json` (id, title, short
and long description, author, icon, install sources; optional homepage, tags, categories) and
an icon (PNG or JPEG, at most 100 KB, 256×256 recommended), added by pull request
([CONTRIBUTING.md](https://github.com/microsoft/CmdPal-Extensions/blob/main/docs/CONTRIBUTING.md)).
The Gallery hosts nothing; it points to an install source, WinGet or the Microsoft Store, where
the extension must already be published.

Publishing to the Store
([Learn](https://learn.microsoft.com/en-us/windows/powertoys/command-palette/publish-extension-store)):
reserve the product name in Partner Center (free for individual developers), copy its
`Package/Identity/Name`, `Package/Identity/Publisher` and `Package/Properties/PublisherDisplayName`
into `Package.appxmanifest` and the project (`AppxPackageIdentityName`, `AppxPackagePublisher`,
`AppxPackageVersion`), provide the Store's icon set (Square44x44Logo, SmallTile,
Square150x150Logo, LargeTile, Wide310x150Logo, SplashScreen, StoreLogo), build MSIX packages
for x64 and ARM64, bundle them into one `.msixbundle`, upload it in Partner Center, and pass
certification. The Store signs the package and updates it.

Raised on 2026-11-13.

**Scope Decisions**:
- **Published now, through the Store** (the author, 2026-11-13): supersedes CPS-002's
  "Signed for the author's machine ... Gallery or WinGet only once others are to use the
  extension". The Store, not WinGet: it keeps the MSIX package the repository builds, signs it,
  and updates it; WinGet's documented path for extensions is an unpackaged EXE installer
  (Inno Setup, COM registration in the registry), which would replace the packaging.
- **CI builds the bundle, the author submits**: the `.msixbundle` (x64 and ARM64) is a CI
  artifact; the Partner Center account, the name reservation, the submission and the Gallery
  pull request are the author's steps, as they need the author's accounts.
- **Gallery id** `xxthunder.shortcuts`, folder `extensions/xxthunder/shortcuts/`, install
  source `msstore` with the Store product ID.

- **Supersedes CPS-002e** (the author, 2026-11-13): the author installs from the Store too;
  no self-signed certificate. The epic CPS-002's acceptance criteria are checked on the Store
  package.

**Acceptance Criteria**:
- [ ] The package identity and publisher in `Package.appxmanifest` and the project are the ones Partner Center reserved
- [ ] CI builds an `.msixbundle` with x64 and ARM64 packages and the Store's icon set, as an artifact
- [ ] The extension passes Store certification and installs from the Microsoft Store
- [ ] A pull request to `microsoft/CmdPal-Extensions` adds `extensions/xxthunder/shortcuts/` with `extension.json` and the icon, and is merged
- [ ] Shortcuts appears in Command Palette's Extension Gallery and installs from there
- [ ] The Store package is installed on the author's machine and the epic CPS-002's acceptance criteria hold there
- [ ] The README says how to install it from the Gallery or the Store

**Dependencies**:
- [CPS-005](cps-005.md): the Store and the Gallery need an icon of its own; the template's placeholders do not pass.

**Open Questions**:
- Is the name "Shortcuts" still free in the Store, or does the listing need another name? Decided when the author reserves it.
- Does the Store listing need a privacy policy? The extension reads local folders only and sends nothing; checked during the submission.
