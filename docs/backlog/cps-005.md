# [CPS-005] The extension shows its own icon

**Status**: Open
**Priority**: Medium
**Component**: `src/CmdPal.Extension.Shortcuts/Assets/`, `src/CmdPal.Extension.Shortcuts/ShortcutsCommandsProvider.cs`

**Summary**:
As a user of Command Palette, I want the extension to have an icon in the list of installed
extensions, so that I recognise it at a glance.

**Description**:
Found in the UAT of CPS-002c: the list of installed extensions shows no icon for it. The
provider's `Icon` points to `Assets\StoreLogo.png`, and the package logos in `Assets/` are the
template's placeholders. Open: an icon of its own (PNG assets in the sizes the manifest names) or
a Segoe Fluent glyph for the provider icon, which needs no image files.

**Acceptance Criteria**:
- [ ] Command Palette's list of installed extensions shows an icon for the extension
- [ ] The package logos in `Assets/` are no longer the template's placeholders
